# Optional Challenges - Lab 3

**These challenges are optional.** Try them once Lab 3 passes every test. They are
not assessed, and they do not affect your lab result.

Each challenge has its own file. Write your program below the header.

| File | Challenge |
|---|---|
| `sum_even.py` | Challenge 1 - Sum of Evens |
| `count_digits.py` | Challenge 2 - Count Digits |
| `sum_digits.py` | Challenge 3 - Sum of Digits |

## Challenge 1: Sum of Evens

1. Ask for the start number with the prompt `Start: `
2. Ask for the end number with the prompt `End: `
3. If the start is greater than the end, print `Invalid`.
4. Otherwise, add up every EVEN number from the start to the end, including the
   end, and print `Sum: ` followed by the total.

For example, a start of `1` and an end of `6` prints `Sum: 12`.

## Challenge 2: Count Digits

1. Ask for a positive whole number with the prompt `Number: `
2. Use a loop to count how many digits it has. Do not use `len()`.
3. Print `Digits: ` followed by the count.

For example, `123` prints `Digits: 3`.

## Challenge 3: Sum of Digits

1. Ask for a positive whole number with the prompt `Number: `
2. Use a loop to add up its digits.
3. Print `Sum of digits: ` followed by the total.

For example, `123` prints `Sum of digits: 6`.

Hint for 2 and 3: `num % 10` gives the last digit, and `num // 10` removes it.

Code. Your output appears in the terminal at the bottom.
